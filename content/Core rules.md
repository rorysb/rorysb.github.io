### The target

The target is determined by adding the relevant attribute and skill.

### The dice pool

The dice pool, by default, is 2d20. This can be increased by purchasing further d20s with action points.

| Dice pool | Bonus d20s | AP cost |
| --------- | ---------- | ------- |
| 2d20      | -          | 0       |
| 3d20      | + 1d20     | 1       |
| 4d20      | + 2d20     | 3       |
| 5d20      | + 3d20     | 6       |
